# Low Poly Rainbow Sphere Screensaver
My first ever attempt at creating a screensaver.

## Installation
1) Go to this link to download the .zip: [Click to download](https://drive.google.com/uc?export=download&id=1IPh3vAGM4Sriz07kF0JxR9f8_ke9UgMo)

2) Extract the entire .zip file

2) Right click "Rainbow Sphere Screensaver.scr" and select "Install".

Open "licenses.html" for information regarding open source software used by the app.
